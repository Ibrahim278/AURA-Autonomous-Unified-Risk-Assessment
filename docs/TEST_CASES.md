# AURA test cases

A checklist to confirm AURA is installed, running and behaving as designed. Work top to bottom.
Every expected value below was checked against the default demo mission (lunar surface base,
60 days, seed 42).

**Before you start:** run the back end (`cd backend && python -m uvicorn aura.main:app --reload`)
and the front end (`cd frontend && npm run dev`), then open http://localhost:5173.
**To reset at any time:** switch the header's environment to "ISS" and back to "Lunar surface
base". This regenerates the mission and clears check-ins. Restarting the back end also resets everything.
